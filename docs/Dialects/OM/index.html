For more information about the Object Model dialect, see the Object Model Dialect Rationale.

om.any_cast (::circt::om::AnyCastOp)

Cast any value to any type.

Syntax:

operation ::= `om.any_cast` $input attr-dict `:` functional-type($input, $result)

Casts any value to AnyType. This is useful for situations where a value of AnyType is needed, but a value of some concrete type is known.

In the evaluator, this is a noop, and the value of concrete type is used.

Traits: AlwaysSpeculatableImplTrait

Interfaces: ConditionallySpeculatable, InferTypeOpInterface, NoMemoryEffect (MemoryEffectOpInterface)

Effects: MemoryEffects::Effect{}

om.basepath_create (::circt::om::BasePathCreateOp)

Produce a base path value

Syntax:

operation ::= `om.basepath_create` $basePath $target attr-dict

Produces a value which represents a fragment of a hierarchical path to a target. Given a base path, extend it with the name of a module instance, to produce a new base path. The instance is identified via an NLA. Once the final verilog name of the instance is known, this op can be converted into a FrozenBasePathOp.

Example:

hw.module @Foo() -> () {
  hw.inst "bar" sym @bar @Bar() -> ()
}
hw.hierpath @Path [@Foo::@bar]
om.class @OM(%basepath: !om.basepath) {
  %0 = om.basepath_create %base @Path
}

Traits: AlwaysSpeculatableImplTrait

Interfaces: ConditionallySpeculatable, InferTypeOpInterface, NoMemoryEffect (MemoryEffectOpInterface), SymbolUserOpInterface

Effects: MemoryEffects::Effect{}

Attributes:

AttributeMLIR TypeDescription
target::mlir::FlatSymbolRefAttrflat symbol reference attribute

Operands:

OperandDescription

Results:

ResultDescription

om.elaborated_object (::circt::om::ElaboratedObjectOp)

Object value with explicit field operands

Syntax:

operation ::= `om.elaborated_object` $className `(` $fieldValues `)` attr-dict `:`
              functional-type($fieldValues, $result)

om.elaborated_object denotes an object value whose fields are given explicitly as operands. The operands correspond to the referenced class fields in their declared order.

This operation is for internal use only and is not intended to be created by frontends. It is generated by optimization and elaboration passes.

Interfaces: SymbolUserOpInterface

om.prop.eq (::circt::om::PropEqOp)

Compare two OM property values for equality

Syntax:

operation ::= `om.prop.eq` $lhs `,` $rhs attr-dict `:` type($lhs)

Compare two OM property values (String, Integer, or Bool) for equality, returning a 1-bit integer (i1) result. Returns 1 if the values are equal, 0 otherwise. Both operands must have the same type.

Example:

%2 = om.prop.eq %0, %1 : !om.string
%3 = om.prop.eq %4, %5 : !om.integer
%6 = om.prop.eq %7, %8 : i1

Traits: AlwaysSpeculatableImplTrait

Interfaces: ConditionallySpeculatable, InferTypeOpInterface, NoMemoryEffect (MemoryEffectOpInterface)

Effects: MemoryEffects::Effect{}

Operands:

OperandDescription
lhsA type that represents a string. or A type that represents an arbitrary width integer. or 1-bit signless integer
rhsA type that represents a string. or A type that represents an arbitrary width integer. or 1-bit signless integer

Results:

ResultDescription
result1-bit signless integer

om.property_assert (::circt::om::PropertyAssertOp)

Assert that a boolean property holds at evaluation time

Syntax:

operation ::= `om.property_assert` $condition `,` $message attr-dict `:` type($condition)

Asserts that $condition (a 1-bit integer) is non-zero when evaluated by the OM evaluator. If the evaluator resolves the condition to zero, evaluation fails with $message.

Example:

om.unknown (::circt::om::UnknownValueOp)

An operation with an unknown value used to tie-off connections

Syntax:

operation ::= `om.unknown` attr-dict `:` type($result)

An operation that is used to tie-off connections to objects for which we do not care about the value being used.

This is used in situations where a class exists and is instantiated, but the instantiator has no reasonable value that it can or should drive.
