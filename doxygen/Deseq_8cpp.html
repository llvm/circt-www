◆ inferRegisterPreset()

LogicalResult inferRegisterPreset ( seq::FirRegOp regOp,
DriveInfo & drive )
static

Attempt to find and set an preset (initializer) value for the newly created register.

This needs to be a constant value that is either used to initialize the signal itself, or is unconditionally driven to the signal at the same time the register op begins driving the signal. If such an initial drive is found, the constant drive operation(s) are erased. Returns failure if mutiple conflicting initial drivers are found, or if a non-constant value would be inferred from a signal initializer.
