◆ ensureDescendingOrder()

template<typename RangeT>
void ensureDescendingOrder ( RangeT & range,
const slang::ast::Type & type )
static

Ensures that the given range is in "descending" order.

type must have a fixed range. If the range is defined such that left < right, the range is reversed.

For example: [3:0] => do not reverse [0:3] => reverse

The resulting range is suitable for passing to ops like ConcatOp and packed ArrayCreateOp which expect operands to be in descending order of bit significance. Do not call on unpacked arrays, whose element indexing logic (getSelectIndex / translateIndex) already maps ascending indices to descending storage order.
