Detailed Description

A client for the cosim RPC server.

Hides the WebSocket + JSON transport behind a small C++ API; see cosim-protocol.md for the wire format.

Connect to a client-bound channel and receive messages via callback.

maxInFlight is the maximum number of frames the simulator may have in flight for this channel; zero means unbounded. A frame stops counting once callback returns true for it. Returns a handle that disconnects when destroyed.

◆ tryWriteToServer()

bool RpcClient::tryWriteToServer ( const std::string & channelName,
const std::vector< MessageData > & frames,
bool force = false )

Non-blocking send of one message, split into frames, to a server-bound channel.

If the channel is below its in-flight limit, sends all of them (possibly overshooting the limit by frames.size() - 1) and returns true. Otherwise sends nothing and returns false. With force, sends regardless of the limit (but still counts the frames as in flight); for the rest of a message whose first part was admitted.

Send a message to a server-bound channel.

Blocks while the channel's in-flight limit is reached. Throws if the connection is lost. Frames sent before the simulation has connected its end of the channel are held by the server (and count as in flight), not dropped.
