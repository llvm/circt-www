template<typename T, bool SkipTypeCheck = false>
bool esi::TypedWritePort< T, SkipTypeCheck >::tryWrite ( std::unique_ptr< T > & data)
inline

Non-blocking write by taking ownership.

On success, data is consumed (left null) and true is returned. On failure, data is left untouched so the caller can retry. If T is a SegmentedMessageData, this hands the message directly to the port's segmented tryWrite path.
