Compute cofactor of a Boolean function for a given variable.

A cofactor of a function f with respect to variable x is the function obtained by fixing x to a constant value:

  • Negative cofactor f|x=0 : f with variable x set to 0
  • Positive cofactor f|x=1 : f with variable x set to 1

Cofactors are fundamental in Boolean function decomposition and the Shannon expansion: f = x'*f|x=0 + x*f|x=1

In truth table representation, cofactors are computed by selecting the subset of minterms where the variable has the specified value, then replicating that pattern across the full truth table width.

This function returns a pair of cofactors (negative, positive) for the specified variable index.
