Given a signal or a projection, find the root signal declaration by traversing the projection chain.

Optionally, if the projection chain is fully constant, return the portion of the original signal that this operation probes or drives. A null Operation is returned if the use-def chain does not bottom-out in a signal declaration, and a null range is returned if a dynamic index is found.
