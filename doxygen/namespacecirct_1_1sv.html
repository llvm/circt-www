Create nested ifdef operations for a list of macro symbols.

For each macro, creates an ifdef with a then branch and an else branch. The then branch is provided by the thenCtor callback, which receives the index of the current macro (0-based).

Example: createNestedIfDefs({macro1Attr, macro2Attr}, ...});

Generates: ifdef MACRO1 // thenCtor(0) else ifdef MACRO2 // thenCtor(1) else // defaultCtor() endif endif
