Detailed Description

Options that control how Verilog input files are parsed and processed.

See slang::driver::Driver::Options for inspiration. Also check out Driver::addStandardArgs() for some inspiration on how to expose these on the command line.

◆ Mode

enum class circt::ImportVerilogOptions::Mode
strong

Limit importing to linting, parsing, or elaboration only.

Enumerator
OnlyLint 

Only lint the input.

OnlyParse 

Only parse the input syntax and report parse diagnostics.

OnlyImport 

Parse and elaborate the input and convert it to Moore dialect ops, without running any transformation passes.

Full 

Perform a full import and mapping to the core dialects.
